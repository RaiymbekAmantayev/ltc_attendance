# LTC · Личный кабинет преподавателя (v0.3)

Telegram Mini App для преподавателей + админка `/admin`. Node.js · Express 5 · MySQL. Реализует ТЗ v0.1 от 14.09.2026
(отметка посещаемости, оценок и темы → HollyHop через сервер-посредник) и добавляет разделы руководства из проекта «Академчасть».

## Запуск
```bash
npm install
cp .env.example .env        # заполнить BOT_TOKEN, HH_*, ADMIN_PASS, APP_URL
npm run init-db             # создаёт базу; на старой базе (v0.1/0.2) безопасно добавляет новые колонки
npm start
```
Демо без HollyHop: `HH_MOCK=1`, затем `node scripts/seed-demo.js <ваш_telegram_id> [id_координатора]`.
Тесты (нужна локальная MySQL/MariaDB, база `ltc_test` создаётся сама): `npm test`.

## Что добавлено из архива LTC
- **Роли** по Telegram ID: преподаватель · координатор · директор (`DIRECTOR_TG_IDS` или роль в `/admin`).
- **Обзор** (руководство): плитки, «сегодня не отмечено», столбцы по дням/филиалам/статусам, проблемные отметки.
- **Группы**: заполняемость, убыточные (`< LOW_FILL_THRESHOLD`), перебор, статус отметки, карточка группы (состав + посещаемость), назначение замены.
- **Преподаватели**: нагрузка, посещаемость, дисциплина отметок; **«Профиль»** преподавателя за месяц.
- **CSV-выгрузки** (группы, преподаватели, отметки, сотрудники).
- **Клиент HollyHop**: повторы с jitter, `Retry-After`, таймаут, ограничение частоты, кэш 30 с, типизированные ошибки.
- **Безопасность**: CSP, `nosniff`, `no-store` для API, лимит запросов, лимит неверных паролей админки, лог без query/initData, `/healthz`.
- **Дизайн**: бренд-система LTC (Manrope, #883DF7→#C558F8, тёмная/светлая тема, только столбцы/плитки/таблицы), безопасные зоны, кнопка «Назад» Telegram.

## Тестирование в HollyHop
Результаты теста пишутся в HollyHop методом `AddEditEdUnitTestResult` (`/Api/V2/AddEditEdUnitTestResult`) вместе с посещаемостью (`SetStudentPasses`), в той же идемпотентной очереди.

| Что | Значение |
|---|---|
| Группа | `edUnitId = 31`; список групп (ID групп, не типов теста!) — `HH_TEST_EDUNIT_IDS` (через запятую). Пусто — тест пишется для всех групп |
| Тип теста | `131` — иностранный преподаватель (lang=en), `132` — местный |
| Навыки 131 (Foreign) | 8 Was present for (min) — макс. 45, всегда 45 по умолчанию · 11 Homework — макс. 5, порог 4 · 17 Discipline/Engagement — макс. 5, порог 4 |
| Навыки 132 (Local) | 8 Was present for (min) — макс. 45, всегда 45 по умолчанию · 13 Домашнее задание — макс. 5, порог 4 · 18 Дисциплина/Активность — макс. 5, порог 4 |

Набор навыков типа теста отправляется целиком; баллы не больше максимума, иначе 422. Тест не пишется пропустившим. Комментарий уходит в `commentHtml` (экранируется). Порог успешности — визуальная подсказка и метрика «прошли порог» в статистике. Конфигурация — `src/config/testing.js`.
